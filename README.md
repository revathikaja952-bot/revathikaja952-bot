## 📊 Featured projects

### 1. [Customer Churn Analysis](https://github.com/revathikaja952-bot/Customer-Churn-Analysis)
End-to-end churn analysis on 7,043 telecom customers using SQL Server and Power BI.
- Built a master SQL view and 20 DAX measures, and designed a 4-page dashboard
- Found a **26.54% churn rate** and about **₹139K monthly revenue loss**
- Identified the highest-risk segments: month-to-month contracts (42.71%) and electronic check payments (45.29%)
- Estimated about ₹32.7K per month in potential savings from the recommended actions

**Tools:** SQL Server · Power BI · DAX · T-SQL

### 2. [Banking NPA Dashboard (Loan Portfolio & NPA Monitor)](https://github.com/revathikaja952-bot/Banking-NPA-Dashboard)
End-to-end banking analytics project: Python data generation, SQL Server cleaning and validation, a Power BI star schema and a 3-page dashboard.
- Generated a synthetic loan book (9,994 loans, 175K repayment records) with Python
- Wrote 8 reconciliation checks and SQL views using CTEs, `LAG()` and `RANK()`
- Built about 40 DAX measures covering GNPA %, SMA buckets, slippage and month-over-month change
- Added drill-through, a report tooltip and row-level security (static by region, dynamic by branch manager)
- Found GNPA of 7.66% and an East-region Personal Loans hotspot at 18.9%

*Note: the data is synthetic. It demonstrates the method and does not describe a real bank.*

**Tools:** Python · pandas · NumPy · SQL Server · Power BI · DAX
